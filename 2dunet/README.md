# 2D U-Net

2D U-Net was attempted for segmentation of fluorescence and autofluorescence (label-free fluorescence) microscopy recordings. Autofluorescence segmentations were unsuccessful. This folder is a collection of files related to the training 2D U-Net models. When the clean-up of this repo is complete or has reached a point of orderly functionality, this folder can be safely deleted. No 2D U-Net related files from this MSc project will be used in the future and are archived in the project repo's git histories.

- `class_label_balance_randomiser.py`: Incomplete, not used in the end. Apparently intended for a one-time task.
